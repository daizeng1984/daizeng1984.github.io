# Tools
Firefox -> Orion : Natively faster on mac and you can import major browser's settings (File-\>Import). You can also have Firefox. Such a great surfing tool that I wish it can be in Linux/Windows. Unfortunately it doesn't have seamless cloud account to transfer your password but you can export and import in some way.
Spotlight -> Verve : Light tool that doesn't look sneaky. Spotlight behaves like spyware. Replaceable by any tools: Alfred, Sol, ... I just picked open source and rust flavored Verve for modern feeling. It's so fresh that no one bring it to homebrew.
iTerm2 -> Alacritty : Wow, didn't expect alacritty such heavy flavored gpu app would beat iTerm2?! With tmux, I'm not really needing any tab magic that iTerm provides... sorry.
Steam -> X : just don't use these sneaky apps. It just try to suck your power blood. Just download the app with steam and quit. Try to run app standalone!
Turbo-Booster-Switcher: just need it to turn off intel's turbo mode

```
Go to System Preferences, Accessibility, Display, and turn on all the options to "Reduce motion", "Increase contrast" (incl. "Reduce Transparency"), "Differentiate without color".

Also, go to System Settings, Dock, and select "Minimize windows using:" "Scale effect" (instead of "Genie effect").
https://apple.stackexchange.com/questions/389863/how-can-i-disable-intel-turboboost-and-hyper-threading
```
