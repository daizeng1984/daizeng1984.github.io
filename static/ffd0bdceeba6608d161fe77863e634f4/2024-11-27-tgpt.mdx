I've been waiting for ages...Long live the terminal!...

# Why
Terminal should be the most efficient and least distractive user interface for LLM. Most of my queries are not complicated (no multimedia). I'm mostly in terminal if I need to do doc. My queries are usually old knowledge refresh (best for small brain), boilerplate code and examples, and english writing revision. I don't need model to solve my problems. It could sometime but I don't relies on that and always keep skeptical about its "answer". LLM still didn't get AGI type of reasoning after all. There are clearly still some gap. I'd define the LLM as a super powerful search or recommendation engine. It now replaces 50% of my google search if the queries fall into the categories mentioned before. 

From user experience perspective, I found myself consistently switching between browser and terminal. It'll be nicer to have less UI travel if something like this can be done in terminal. Plus, functionality in terminal can be powerful when we need improvement and automation for our tools.

# Our Savior TGPT
This is a free to use gpt. Might not be as powerful as chat gpt. But the good part is that you don't need API key and pay anything! It also provides a lot of model option or AI provider. AI provider like duckduckgo seems to be very good (gpt-4omini) and less worries regard the user data as well. It's also fast! The best usecase

You can find the tgpt [here](https://github.com/aandrew-me/tgpt)
