I've been waiting for ages...Long live the terminal!...

# Why
Terminal should be the most efficient and least distractive user interface for LLM. Most of my queries are not complicated (no multimedia). I'm mostly in terminal if I need to do doc. My queries are usually old knowledge refresh (small brain), boilerplate code and examples, and english writing revision. I found myself consistently switching between browser and terminal in my daily computer life. It'll be nicer to have less UI travel. 

# Our Savior TGPT
This is a free to use gpt. Might not be as powerful as chat gpt. But the good part is that you don't need API key and pay anything! It also provides a lot of model option or AI provider. AI provider like duckduckgo seems to be very good (gpt-4omini) and less worries regard the user data as well. It's fast and sounds illegal.

You can find the tgpt [here](https://github.com/aandrew-me/tgpt)
