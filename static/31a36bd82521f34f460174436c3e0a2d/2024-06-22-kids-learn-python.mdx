Python is extremely human friendly to write. It might be best for kids to learn coding...


# Background

My elder son seems to show strong interesting in coding and visualization of data. I think it'll be the a good time to introduce him. This post just records what I taught as I go along this summer and maybe it can even be reused when younger son needs.


# Python Basics
Design a interesting final project: a global wind visualization, since my kid is really interested in weather in google map

## Introduction
Just give him a warm welcoming introduction of what is the Python. Why it is called Python. Show him a few fancy typing tools and REPL console etc. Trying to make it fancy enough for kids...

Code Monkey's free intro seems to be great: https://www.youtube.com/watch?v=bdUqQidffPE 

## String and Print
A introduction to "double" and "single" quote string and first time ever function `print`. He doesn't need to know all of the knowledge point but need to understand, if he type something to Python REPL Console, he'll get stuff print out.

First time to make his hand dirty to type things and see computer response. It's great to encourage him. Typing can be slow. Just be patient and make every typing looks rewarding. My son sepcially loves syntax color highlight. So iPython like REPL would be best. If there's some rewarding animation that'll be great for most kids!


## Variables
Treat variables like a box with name label, this can help kids understand more about how variables works. It's great if we could use some real stuff to show that.
