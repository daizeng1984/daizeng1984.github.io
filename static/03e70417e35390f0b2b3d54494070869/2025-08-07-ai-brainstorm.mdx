# 3D World

Come on! 这是语言模型！文字进文字出。所以3d世界的信息完全没有！喝水对于这个模型来说不是用一只手拿起冰凉的可能还很重的mug杯子，享受清凉的带着清新味道的水。所有的信息都是通过文字连接起来的。不是说大模型不知道喝水更杯子的关联，相反可能大模型的训练数据里面已经包括了所有跟喝水相关的互联网所有知识！所以问所有跟喝水相关的互联网科学文献找的到的都会。但是模型永远不会有人类的体验，喝水就是跟其他知识连接在一起的节点。所以LLM暂时还无法走出互联网。Agent或者LLM主导的互联网接口可能是未来的方向。

# LLM as new UI
实际上，人类的语言确实是superintelligence的基石。把喝水这样复杂的涉及到肌肉协作和感官刺激各种复杂生物计算总结成简单的word。Brilliant! 凭借强大的搜索能力，模型能瞬间生成普通人需要很多时间才能产生的内容。但是这些知识现在还很难看到模型的。
